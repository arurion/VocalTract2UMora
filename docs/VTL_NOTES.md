# VocalTractLab (VTL) 調査メモ

対象: https://github.com/TUD-STKS/VocalTractLabBackend-dev （C++、GPL-3.0、本プロジェクトと互換）。
**読んだ範囲**: `LfPulse.cpp`、`Glottis.h`、`GeometricGlottis.h`、`Tube.h`、`TdsModel.h`、`Synthesizer.h`、`Speaker.h`、`VocalTract.h`（いずれも全体または公開インターフェース）。
**未読**: `VocalTract.cpp`(250 KB)、`TdsModel.cpp`(83 KB)、`GesturalScore.cpp`(130 KB)、`TwoMassModel.cpp`、`TriangularGlottis.cpp`、`AnatomyParams.cpp`、`Surface/Geometry/Splines`。移植に着手する前に該当部分を読むこと。

## 1. 合成パイプライン

```
GesturalScore ─▶ VocalTract パラメータ ─▶ Tube(断面列) ┐
                                          Glottis パラメータ ┤─▶ Synthesizer.add() ─▶ TdsModel ─▶ 音声
                                                             └ 約2.5 ms(110 サンプル@44.1 kHz)ごとに、管形状を線形補間
```

- **Tube**: 1 cm 刻みの短い管の列。気管 23 + 声門 2 + 咽頭 16 + 口腔 24 + 鼻腔 19 + 副鼻腔 4 + 梨状窩 5。各区間は面積・長さ・体積・壁の質量/抵抗/剛性・「どの調音器官の領域か」(声帯/舌/下切歯/下唇/他)を持つ。調音器官の情報は摩擦音の雑音源の生成に使われる。
- **TdsModel**: 分岐管を電気回路(L, C, R)に見立てて時間領域で解く。枝電流を毎サンプル、SOR(ガウス・ザイデル)かコレスキー分解で解く。乱流損失、軟らかい壁、雑音源(単極子/双極子)、皮膚放射、梨状窩、経軟口蓋結合などをオプションで切り替える。全て CGS 単位。
- **Glottis(基底クラス)**: 制御パラメータの先頭 2 つは常に `FREQUENCY` と `PRESSURE`。`incTime(dt, 4点の圧力)` で時間発展し、`getTubeData` で声門の管(長さ・断面積)を返す。
  - `GeometricGlottis`(既定): F0, 肺圧, 下端/上端 X, チンク面積, 位相遅れ, 相対振幅, 二重脈動, パルス歪度, フラッター, 気息強度。静的パラメータは厚さ・長さ・安静時 F0・チンク長。
  - ほかに `TwoMassModel`、`TriangularGlottis`。
  - 音源フィルタ型の励振として `LfPulse` / `ImpulseExcitation` / `VowelLf` もある。
- **LfPulse**: OQ/SQ/TL(Te = OQ, Tp = Te·SQ/(1+SQ), Ta = TL)で指定し、ε は戻り相の連続条件(ニュートン法)、α は正味流量ゼロ条件(はさみ打ち)で求める。本プロジェクトの `lf.rs` と同じ数式構造。

## 2. 検証

`lf.rs` の `agrees_with_vocaltractlab_reference_values` は、VTL の LfPulse の式から求めた (ε, α) の数値を基準にして、3 組の独立なパラメータで私たちのソルバーと一致(ε 相対 1e-3、α 絶対 2e-3)を確認する。**数値のみを使用し、VTL のコードは含めていない。**

## 3. 本プロジェクトへの示唆

1. **音源は 2 系統を持つ**:
   - (A) LF 流量源を声門位置に入れる(`TdsModel.flowSourceAmp` に相当)。決定的でパラメータが少なく、声質エディタ(①)がそのまま使える。oto.ini の時刻算出は、まずこちらで確実に行う。
   - (B) 自励振動の声門(`GeometricGlottis` 相当)。肺圧 Breath で駆動する物理系。
2. **tract-sim の最初の一歩**: 区間(Tube)モデルと TDS ソルバーの最小サブセットを Rust で実装し、LF 流量源で駆動する。検証として「一様管 17.5 cm のスペクトルピークが一様管近似の共鳴(500/1500/2500 Hz、骨格エディタの表示値)の近傍に出る」ことを確認する(唇の放射補正で少し低くなる想定)。
3. **子音プレビューの要件**(舌と口蓋の接触判定、最小断面積)には、面積関数だけでなく矢状断面の輪郭が必要。VTL は調音パラメータ(顎・舌・唇・軟口蓋など約 20 個)から輪郭と面積関数を作る。**面積関数レベルのターゲットだけで進めるか、調音パラメータモデルまで移植するかは、設計上の大きな分岐**であり、`feat/consonant-editor` の前に決める。
4. **話者データ**: VTL は `.speaker` ファイル(解剖データ)を使う。コードとは別に、データの再利用条件を確認してから取り込むこと。
5. **計算量**: VTL は 44.1 kHz のサンプル毎に枝電流の連立方程式を解く。Wasm 単一スレッドで、Android 端末でも非リアルタイムのバッチ生成が現実的な速度で回るかを、tract-sim の早い段階で計測する。

## 4. 決定: 調音パラメータモデルまで移植する (案B)

オーナーの目標(舌と口蓋の接触ハイライト、3 点コーナー母音補間、無声子音のスクラブデバッグ)に近づくため、面積関数だけの簡易版ではなく VTL 型の調音モデルを移植する。

### VocalTract の構造 (`VocalTract.h` より)
- **調音パラメータ 19 個**: `HX HY`(舌骨) `JX JA`(顎) `LP LD`(唇) `VS VO`(軟口蓋) `TCX TCY`(舌体) `TTX TTY`(舌尖) `TBX TBY`(舌背) `TRX TRY`(舌根) `TS1 TS2 TS3`(舌の側面)。各パラメータは `x`(指定値)と `limitedX`(生体力学的制約後)、`min/max/neutral` を持つ。
- **Shape = 名前 + 19 個のパラメータ値**。これが「基準声道形状」の表現に使える。/aka/ /iki/ /uku/ の 3 形状と、その重心補間・口蓋化の手動上書きは、19 次元ベクトルの補間と上書きとして素直に実装できる。
- **3D 表面モデル**: 上顎(口蓋・歯・カバー)、下顎、唇、舌(動的 33 + 静的 4 リブ × 11 点)、軟口蓋、口蓋垂、喉頭蓋、咽頭、放射面などを「リブ」の列で持つ。
- **断面の計算**: 中心線(129 点)に沿って横方向 96 サンプルの断面プロファイルを取り、面積関数(咽頭 16 + 口腔 24 区間)を得る。
- **Anatomy**: 話者固有で調音と独立な形状(口蓋の点列・角度、顎の支点、歯、舌の半径、唇幅、軟口蓋の形状、咽頭・喉頭・喉頭蓋の寸法、梨状窩、気管下腔長、鼻腔長、パラメータごとの速度係数など)。`.speaker`(XML)から読み込む。

### 話者データ
`resources/JD3.speaker`(約 91 KB)が同梱されている。VTL リポジトリは GPL-3.0 で、README にデータ用の別段のライセンス記述は無い。**GPL-3.0 のリポジトリの一部として配布されているため、GPL-3.0 として扱い、本リポジトリの `resources/JD3.speaker` に無改変で同梱した**(`THIRD_PARTY_NOTICES.md` に記録)。作者側から別の条件が示された場合は同梱をやめ、ユーザーが自分のファイルを開く方式に切り替える。

### 改訂したロードマップ
1. `feat/tract-sim`: Tube(区間列)と TDS ソルバー(Rust)、LF 流量源で駆動、一様管での検証、Wasm での速度計測
2. `feat/vocal-tract-model`: `.speaker` XML の読み込み → 調音パラメータ → 輪郭・面積関数。矢状断面の描画、舌口蓋の接触判定
3. `feat/consonant-editor`: Shape(19 次元)の 3 点補間と口蓋化の上書き
4. `feat/scrub-preview`: 時間軸のスクラブ、最小断面積・声門開口度・接触ハイライト
5. `feat/batch-oto-zip`: バッチ生成と oto.ini の自動算出、ZIP 出力

## 5. 進捗: tract-sim v0 (`tds.rs`, `tube.rs`)

`TdsModel.cpp` の中核(区間の L/C/R、θ 法 θ=0.505、壁の振動、ベルヌーイ抵抗、声門の非線形抵抗、D/E、行列の組み立て、コレスキー分解、変数更新)を口腔系のみで Rust に移植した。

- **解法**: 枝電流の行列は対称正定値で疎。接続から非ゼロ位置を作り、記号的に消去(この木構造ではフィルインなし)して、サンプルごとにコレスキー分解する。
- **検証**: 一様管(17.5 cm 相当)をホワイトノイズ流量で励振した伝達関数のピークが 549 / 1497 / 2455 / 3381 / 4307 Hz。F2 以降は一様管近似(1500 / 2500 Hz …)にほぼ一致し、F1 は軟らかい壁の効果で高めに出る(閉じた声門の管で知られる傾向)。声道が長いほど F1 が下がること、肺圧 8 cmH₂O で開いた声門(0.1 cm²)に定常流が流れること、閉じた声門で流れが止まることもテスト。
- **速度**(ネイティブ release): 1 サンプル約 4.2 µs、実時間の約 5.4 倍(44.1 kHz)。行列が実質三重対角なので専用ソルバーで更に高速化できる。Wasm / Android での実測は未実施。
- **未実装**: 鼻腔、副鼻腔、梨状窩、皮膚放射、経軟口蓋結合。

## 6. 進捗: 雑音源 (`tds.rs`)

`calcNoiseSources` / `calcNoiseSample` を移植した。

- **狭窄の検出**: 声門(気息、常時)、舌(最大 2 か所)、下唇。区間の調音器官タグ(`Articulator`)と切歯位置(`Tube::teeth_position_cm`)で決まる。調音パラメータモデル(次のPR群)が各区間にタグを付ける。
- **強さ**: 噴流速度 v = 流量/面積 から `gain · |v|³ · √A`。流量は 500 Hz で平滑化した枝電流(流出のみ)。面積 0.5〜1.0 cm² で 0 へテーパー、0.15 cm² 未満でも 0 へテーパー(クリック防止)。
- **スペクトル**: 調音位置ごとに利得とカットオフを切り替える。/f/(8 kHz)、/p, b/ の破裂(500 Hz)、/s, ʃ/(5 kHz)、/t, d/ の破裂(1.5 kHz、舌尖側面の挙上度で補間)、/x, k/(800 Hz、壁面音源)、気息(10 kHz, 強さは dB)。側面通路(挙上度 < 0)では舌の音源を止める。
- **配置**: 障害物位置を含む区間の上流端・下流端に 2 つの双極子(圧力)源として按分。唇の外は唇端の音源。
- **整形**: 臨界減衰 2 次ローパス(Q=1/√2)、1 kHz 基準で利得-帯域積一定。立ち上がりは √振幅を 3 ms の 1 次フィルタで遅らせ、立ち下がりは即時(破裂の閉鎖直前の摩擦音ノイズを防ぐ)。
- **再現性**: ノイズは xorshift で、`set_noise_seed` により同じ入力から同じ波形が出る(バッチ生成で必要)。

### VTL との差分(意図的)
`calcNoiseSample` は現在振幅が閾値(0.001)未満になると現在値を 0 に戻す。立ち上がりの 1 ステップ目が閾値を下回る弱い音源(44.1 kHz で目標振幅が約 18 以下)は、そのため一度も起動しない。弱い気息雑音(息漏れ声)を出せるように、閾値は出力のゲートにだけ使い、現在値は戻さない形にした。テスト `weak_aspiration_still_starts` で確認している。

### 検証
- /s/ 的な舌の狭窄(0.12 cm²、切歯付近)で、3〜8 kHz のエネルギーが全開の管の約 10 倍以上(テスト)。
- 気息の強さ -40 → -20 dB で雑音エネルギーがちょうど約 100 倍(振幅比に比例)。
- 流れがなければ雑音なし。同じシードで出力が完全一致、別シードで変わる。

## 7. 進捗: 声帯モデルと合成ループ (`glottis.rs`, `iir.rs`, `synth.rs`)

- **`GeometricGlottis`**: 力学方程式を解くモデルではなく運動学的モデル。声帯の下端・上端の変位を位相ワープ付きの正弦で与え、振幅を声門前後の差圧の平方根(Titze 1989)で決める(8000 dPa で約 0.1 cm)。したがって「肺圧が上がると声帯が振動を始める」は、機械的な連成ではなく振幅が圧力で決まる形で再現される。長さは √f0 に比例、薄さは反比例。パラメータは F0、肺圧、下端/上端の変位、チンク面積、位相差、相対振幅、二重脈動、パルス歪度、フラッター、気息強度。範囲外は丸める。
- **`iir.rs`**: スミス方式のチェビシェフ(リップル 0.5 %)。声門上圧の 25 Hz 4 極、出力の 12 kHz 8 極に使う。
- **`synth.rs`**: VTL の `Synthesizer::add` と同じサンプル毎の順序(声門形状 → 管 → 4 点の圧力 → 声帯の時間発展 → TDS → 流量の時間微分 → 出力フィルタ、スケール 1e-7)。
- **検証**: 声門面積が F0 通りに開閉(1 秒で 98〜102 周期)、合成音の F0 が指定値の ±4 Hz 以内で周期性が高いこと、F0 を 180 Hz にすると追従すること、肺圧 0 で無音、肺圧が低いと小さいこと。合成した母音のスペクトルは調波の櫛に一様管の共鳴(500/1500/2500 Hz 付近)が重なる。
- **意味**: oto.ini に必要な「声帯振動の開始」は、肺圧と声門パラメータの時系列から声門面積・流量の周期性として検出できる。次は鼻腔、続いて調音パラメータモデル。

## 8. 進捗: 話者ファイルの読み込み (`xml.rs`, `speaker.rs`, `resources/JD3.speaker`)

- **`.speaker` の内容**: 解剖データ(口蓋・顎・舌・唇・軟口蓋・咽頭・喉頭・梨状窩・声門下・鼻腔の寸法)、19 個の調音パラメータの定義(名前・範囲・中立値・速度係数)、声道形状 69 個、声帯(Geometric glottis)の形状。
- **重要な発見**: 子音の基準形状が、**3 つのコーナー母音 /a/ /i/ /u/ の文脈ごとに定義されている**。例: `tt-alveolar-closure(a)` / `(i)` / `(u)`、`tb-velar-closure(…)`、`ll-labial-closure(…)`、`tt-alveolar-fricative(…)`、`tt-postalveolar-fricative(…)`、`tb-palatal-fricative(…)`、`tt-dental-fricative(…)`、`tb-uvular-fricative(…)`、`tt-*-lateral(…)`。VTL 方式の「3 点コーナー母音補間」は、この 3 形状(19 次元ベクトル)を後続母音の位置(母音三角形の重心座標)で補間するもの。検証として、`tb-velar-closure` の舌体位置が /a/ と /i/ の文脈で大きく異なる(/i/ の前で前進する)ことをテストしている。
- **声帯形状**: modal / breathy / pressed / whisper / voiceless-plosive / voiceless-fricative / voiced-plosive / voiced-fricative / h など。無声子音では声門を大きく開く(XB が modal より約 0.05 cm 以上大きい)ことをテストで確認。
- **日本語への当てはめ(案)**: か行 → `tb-velar-closure`、さ行 → `tt-alveolar-fricative`、し・ちゃ行 → `tt-postalveolar-*`、ひ → `tb-palatal-fricative`、ぱ・ば・ま行 → `ll-labial-closure`、た・だ・な行 → `tt-alveolar-closure`、ら行 → 短い `tt-alveolar-closure`(はじき音)、ふ → 両唇の狭め。母音は a e i o u の形状(ドイツ語話者のデータなので日本語の母音に合わせた調整が必要になる可能性がある)。日本語向けの口蓋化(き・け、拗音)は、この補間の結果を手動で上書きする設計。
- **実装**: 依存ゼロの最小 XML パーサーと、読み込み・検証つきのローダー。パラメータの名前・順序は VTL と一致していることを検証し、壊れたファイルは明確なエラーで拒否する。
- **次**: 調音パラメータ → 3D 表面 → 中心線 → 断面 → 面積関数(`calcSurfaces`、`calcTongue`、`calcLips`、`calcCenterLine`、`getCrossProfiles` ほか約 5,000 行)。
